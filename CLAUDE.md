## Working agreements for Claude Code

- Start each milestone in plan mode. Propose files and use cases, then wait for approval.
- Write tests for the domain invariants before implementing them.
- Run `npm run check` before saying anything is done. If it is red, it is not done.
- Ask before adding a runtime dependency, changing a boundary rule, or changing anything in the Security & privacy section.
- Commit at the end of each milestone. Then stop, summarize what was built, and list open questions.
- `prototype/` is a working single-purpose version of this app. Treat it as a reference for behavior only. Do not copy its structure.
